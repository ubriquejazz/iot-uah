Ojo, dentro de una función no se puede usar ‘require’. Es necesario añadirlos todos los ‘require’ en el fichero **settings.js**.  

```
~/.node-red$ cat settings.js

functionGlobalContext: {
	gpio:require('onoff').Gpio,
	i2c:require('i2c-bus'),
	os:require('os'),
	...
	
~/.node-red$ 
```
